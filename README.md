# 🔎 Python Port Scanner

Scanner de portas simples desenvolvido em Python.

## 🎯 Objetivo

Identificar portas abertas em um host alvo, auxiliando na análise de superfície de ataque.

## ⚙️ Funcionalidades

- Escaneia portas de 1 a 1024
- Identifica portas abertas
- Exibe resultado no terminal

## 🛠 Tecnologias

- Python

## ▶️ Como usar

```bash
python scanner.py

Digite o IP alvo quando solicitado.

📌 Exemplo
